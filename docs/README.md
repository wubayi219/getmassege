## 🔄 自动化更新系统

本知识库配备了完整的自动化更新系统：

### GitHub Actions 工作流

#### ⏰ 定时任务
- **运行时间**: 每天 UTC 9:00 (北京时间下午 17:00)
- **任务内容**:
  1. 收集最新信息
  2. 整理信息内容
  3. 更新知识库
  4. 生成每日报告
  5. 生成周报摘要

#### 📊 工作流步骤

```
1. 信息收集
   ↓
2. 内容整理
   ↓
3. 知识库更新
   ↓
4. 每日报告生成
   ↓
5. 周报汇总
   ↓
6. 邮件发送（可选）
```

### 📧 邮件发送设置

要启用每日邮件功能，需要进行以下配置：

#### 步骤 1: 添加 GitHub Secrets
在仓库设置中添加以下机密变量：
- `EMAIL_ADDRESS`: 你的邮箱地址
- `EMAIL_PASSWORD`: 邮箱密码或应用程序密码

#### 步骤 2: 邮件内容
每日邮件包含：
- 📋 今日更新摘要
- 🎯 推荐阅读内容
- 💡 知识点回顾
- 🔗 文档链接

#### 步骤 3: 邮件示例
```
主题: 🌿 山茶油每日信息摘要 - YYYY-MM-DD

内容:
- 今日更新状态
- 推荐阅读
- 知识点汇总
- 相关链接
```
